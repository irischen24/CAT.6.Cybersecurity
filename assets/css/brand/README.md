# CAT.6 official brand assets

Place the official CAT.6 Cybersecurity logo files here (supplied by the project owner — do not redraw):

| File | Use |
|---|---|
| `cat6-logo.png` | Full logo — report cover, Trust Center documents |
| `cat6-logo-horizontal.png` | Compact horizontal lockup, transparent background — navigation bars, headers |
| `cat6-mark.png` | Square symbol — sidebar, collapsed rail |
| `favicon.png` | 32 × 32 / 180 × 180 icon |

Then set the paths in `data/brand.js` (`assets.logo`, `assets.horizontal`, `assets.mark`, `assets.favicon`).
Every page, report and demo document uses `js/ui/brand.js`, so no other file needs to change.
Until then the existing CAT.6 SVG mark is shown.
